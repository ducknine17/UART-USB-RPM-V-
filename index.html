틴시 진단 코드 다운로드
오후 실험 준비 · 연결과 업로드 순서
  1. Teensy 4.1을 USB로 연결하고, 진단 코드를 Arduino IDE에서 엽니다. 같은 이름의 스케치 폴더를 만들겠다는 안내가 나오면 확인합니다. 한글 경로 때문에 컴파일 오류가 나면 스케치와 빌드 경로를 영문 폴더로 바꿔 확인하세요.
  2. 보드: Teensy 4.1 / USB Type: Serial / 포트: 해당 Teensy를 선택해 업로드합니다. 업로드는 기존 틴시 프로그램을 대체하므로 필요한 기존 코드는 보관하세요.
  3. 시리얼 모니터를 닫고, 여기서 ‘Teensy 4.1 진단’을 선택해 장치를 연결합니다. 컨트롤러가 없어도 1초마다 틴시 상태가 도착합니다.
  4. 컨트롤러와 틴시 전원을 끄고, 확인된 컨트롤러 출력 → 틴시 0번(RX1), 통신 GND → GND를 연결합니다. 틴시 1번(TX1)과 컨트롤러 전원선은 연결하지 않습니다.
  5. 틴시는 USB, 컨트롤러는 기존 전원으로 켭니다. 컨트롤러 출력은 Teensy의 3.3V 입력과 호환되어야 합니다. 사양서의 TTL 표기만으로 3.3V라고 확정할 수는 없습니다.
  6. 약 5초 뒤 세 진단 칸을 확인하고 ‘진단 결과 저장’을 누릅니다. 시리얼 모니터와 사이트는 같은 포트를 동시에 사용하지 마세요.

틴시 UART는 코드의 UART_BAUD 값(기본 19200, 8N1)을 사용합니다. 사이트에서 USB 속도를 바꿔도 틴시 UART 속도는 바뀌지 않습니다. 예전 시리얼 모니터 전용 스케치 대신 새 진단 스케치를 업로드하세요.

전압 -- Addr E8 / 0.1V
RPM 후보 -- Addr E2 / MeasureSpeed
라인 전류 -- Addr E8 / 0.25A
MOS 온도 -- Addr D6
모터 온도 -- Addr F4
